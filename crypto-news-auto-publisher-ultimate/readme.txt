== УСТАНОВКА ==

1. Загрузите ZIP через WordPress → Плагины → Добавить новый
2. Активируйте плагин
3. При активации создается первая партия постов АВТОМАТИЧЕСКИ
4. Используйте кнопку "Опубликовать СЕЙЧАС" для ручной публикации

== ГРАФИК ==

Автоматическая публикация: каждые 3 часа
Ручная публикация: в любой момент через админку

== ИСТОЧНИКИ ==

- CoinGecko API (цены, данные монет, изображения)
- Реальные данные в режиме реального времени

== ПОДДЕРЖКА ==

Все посты публикуются со статусом "publish" НЕМЕДЛЕННО.
Изображения загружаются автоматически из CoinGecko.
